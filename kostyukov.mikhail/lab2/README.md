# Лабораторная работа 2

## Задание

Вариант 5. Написать функцию toBinary(num), преобразующую десятичное число в
двоичную строку (без ведущих нулей).

## Реализация

Функия toBinary принимает число в десятичной системе счисления. Происходит
проверка на соответствие числовому типу. Затем используется стандартный алгоритм
перевода числа в двоичную систему счисления. Применяются функции Math.floor() и
Math.abs(). Отрицательные числа после перевода в двоичную запись просто получают
минус.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
