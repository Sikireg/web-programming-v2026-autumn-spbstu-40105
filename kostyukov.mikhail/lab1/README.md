# Лабораторная работа 1

## Задание

Вариант 5. Создать постраничную навигацию как на изображении варианта. Навигация
должна удовлетворять следующим критериям:

- Элементы навигации должны находиться по центру;
- Текст внутри элемента навигации должен быть выровнен по центру по двум осям;
- Фон активного элемента навигации должен отличаться от остальных элементов;
- Фон элементов навигации при наведении должен изменяться.

## Реализация

Для создания навигации был применен `<nav>` с вложенными в него ссылками `<a>`
(каждая ссылка представляет собой класс `pagination-link`). Выравнивание
элементов по центру по обеим осям достигнуто с помощью
`justify-content: center;` и `align-items: center;` у `body`. Текст ссылок
выровнен аналогичным образом в классе `pagination-link`.

## Запуск

Откройте `index.html` в браузере.
