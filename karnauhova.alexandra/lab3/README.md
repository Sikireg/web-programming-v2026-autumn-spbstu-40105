# Лабораторная работа 3

## Задание

Вариант 31 Реализовать функцию `intersection(arr1, arr2)`, которая находит и
возвращает массив общих элементов двух переданных массивов. Порядок элементов в
результирующем массиве не проверяется.

## Требования

- Входные массивы не изменяются (функция чистая).
- Порядок элементов в результирующем массиве не имеет значения.

## Реализация

Экспортируется именованная функция `intersection`. Для обеспечения эффективности
и автоматического удаления дубликатов используется структура данных `Set`.

1. Второй массив преобразуется в `Set` для мгновенной проверки наличия элемента
   (`has`).
2. Первый массив проходит итерацию, и общие элементы добавляются в
   результирующий `Set`.
3. Результирующий `Set` преобразуется обратно в массив с помощью `Array.from()`.

**Входные параметры:**

- `arr1` — массив (`Array`)
- `arr2` — массив (`Array`)

**Возвращаемое значение:**

- `Array` — массив, содержащий уникальные элементы, которые присутствуют и в
  `arr1`, и в `arr2`.
