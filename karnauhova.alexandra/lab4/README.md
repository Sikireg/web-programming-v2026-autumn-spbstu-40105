# Лабораторная работа 4

## Задание

Разработать веб-приложение «Книга рецептов» со следующей функциональностью:

1. Создать класс `Recipe` с полями: `title` (название), `ingredients` (массив
   строк), `steps` (массив строк). Реализовать методы: `addIngredient`,
   `removeIngredient` и геттер `ingredientCount`.
2. Реализовать набор функций для работы с массивом рецептов:
   - Группировка рецептов по количеству ингредиентов.
   - Получение уникального списка всех ингредиентов.
   - Поиск рецептов, содержащих заданный ингредиент.
   - Группировка рецептов по количеству шагов приготовления.
   - Получение списка всех названий рецептов.
3. Реализовать пользовательский интерфейс:
   - Карточки рецептов с отображением названия, ингредиентов, шагов и их
     количества.
   - Кнопки управления: добавление/удаление ингредиента, добавление/удаление
     шага, удаление всего рецепта.
   - Форма для создания нового рецепта.
   - Автоматическое обновление интерфейса при любых изменениях данных.
   - Выполнение всех операций добавления/удаления асинхронно с использованием
     `Promise` и `setTimeout()`.
   - Сохранение и загрузка списка рецептов из `localStorage` для сохранения
     данных между сессиями.

## Реализация

Решение разделено на логические модули для соблюдения принципа единственной
ответственности:

- `model.ts`: Содержит класс `Recipe` и чистые функции для обработки массивов
  рецептов (группировка, фильтрация, маппинг). В методе `removeIngredient`
  используется `splice` для корректной мутации массива.
- `main.ts`: Отвечает за взаимодействие с DOM, управление состоянием и
  асинхронность.
- `styles.css`: Минималистичные стили для адаптивного отображения карточек и
  форм.

**Ключевые архитектурные решения:**

1. **Управление состоянием:** Все данные хранятся в едином массиве `recipes`.
   При любом изменении вызывается функция `mutate`, которая инкапсулирует
   асинхронную задержку (`Promise` + `setTimeout`), сохранение в `localStorage`
   и последующий вызов `render()`.
2. **Делегирование событий:** Обработчик клика навешан на родительский контейнер
   списка (`.list`). Это позволяет корректно обрабатывать нажатия на динамически
   создаваемые кнопки удаления (ингредиентов, шагов, рецептов) без необходимости
   перевешивать слушатели после каждого рендера.
3. **Безопасность:** Перед вставкой пользовательского текста в HTML применяется
   функция экранирования (`esc`), предотвращающая XSS-атаки.
4. **Восстановление состояния:** При загрузке страницы данные из `localStorage`
   парсятся и преобразуются обратно в экземпляры класса `Recipe` для сохранения
   прототипных методов.

## Запуск

Проект использует сборщик **Vite** и TypeScript.

1. Убедитесь, что установлен [Node.js](https://nodejs.org/) (версия 18+).
2. В корне проекта выполните:
   ```bash
   npx vite
   ```
