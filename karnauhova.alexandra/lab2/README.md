# Лабораторная работа 2

## Задание

Вариант 31 Написать функцию `isPerfectNumber`, проверяющую, является ли число
"совершенным" (сумма делителей равна числу, исключая само число).

## Требования

- Входное значение должно быть положительным целым числом
- Число 1 не является совершенным (сумма его делителей без учёта самого числа
  равна 0)
- Для некорректных входных данных (отрицательные числа, ноль, дробные числа)
  функция возвращает `false`

## Реализация

**Входные параметры:**

- `num` — положительное целое число (`number`)

**Возвращаемое значение:**

- `boolean` — `true`, если число совершенное, иначе `false`

Экспортируется функция `isPerfectNumber`. Используется алгоритм перебора всех
чисел от 1 до `num - 1` с проверкой делимости и накоплением суммы делителей.
Функция корректно обрабатывает граничные случаи (отрицательные числа, ноль,
нецелые значения, единица) и возвращает `true`, если сумма делителей равна
исходному числу, иначе `false`.
