# Лабораторная работа 1

## Задание

Вариант 31 Создание каталога товаров, сгруппированных по категориям

**Требования:**

- Создать каталог товаров, сгруппированных по категориям
- Категории и товары должны быть представлены в виде списка
- Внутри каждой категории должен находиться список товаров, относящихся к данной
  категории
- Каждый товар должен содержать:
  - **Название** (выделенное жирным шрифтом)
  - Краткое описание
  - _Цену_ (выделенную курсивом)

**Пример данных:**

- Категория "Электроника":
  - Смартфон X10 — 25000 руб.
  - Наушники AirBuds Pro — 10000 руб.
- Категория "Одежда":
  - Футболка — 1000 руб.
  - Джинсы — 3000 руб.

---

## Реализация

### Структура решения

Проект состоит из двух файлов:

```
├── index.html      # HTML-разметка каталога
└── styles.css      # CSS-стили для оформления
```

### HTML-структура (`index.html`)

**Основные элементы:**

- `<h1>` — заголовок страницы "Каталог товаров"
- `<ul class="category-list">` — неупорядоченный список категорий
- `<li class="category">` — элемент категории
- `<h2>` — название категории
- `<ul class="product-list">` — вложенный список товаров внутри категории
- `<li class="product">` — элемент товара
- `<strong>` — название товара (жирный шрифт)
- `<p>` — описание товара
- `<em>` — цена товара (курсив)

- Использована семантическая вложенная структура списков (`<ul>` внутри `<ul>`)
- Применены семантические теги `<strong>` и `<em>` для выделения важности и
  акцента
- Добавлены классы для удобного стилизации через CSS
- Убран лишний контейнер `<div>` для упрощения структуры

### CSS-стили (`styles.css`)

**Основные стили:**

| Элемент           | Стили                                                |
| ----------------- | ---------------------------------------------------- |
| `body`            | Базовый шрифт Arial, отступы, межстрочный интервал   |
| `h1`              | Центрирование заголовка, отступ снизу                |
| `.category-list`  | Убраны маркеры списка (`list-style: none`)           |
| `.category`       | Отступы между категориями                            |
| `.category h2`    | Размер шрифта, отступы                               |
| `.product-list`   | Стандартные маркеры-диски, отступ слева              |
| `.product strong` | Блочное отображение (каждое название с новой строки) |
| `.product em`     | Блочное отображение цены                             |

## Запуск

1. Убедитесь, что файлы `index.html` и `styles.css` находятся в одной папке
2. Откройте файл `index.html` в любом браузере:
   - Дважды кликните по файлу
   - Или перетащите файл в окно браузера
   - Или нажмите правой кнопкой → "Открыть с помощью" → выберите браузер
