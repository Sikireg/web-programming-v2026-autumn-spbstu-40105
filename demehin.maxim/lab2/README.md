# Лабораторная работа 2

## Задание

Вариант 2 Написать функцию toRoman(num), преобразующую число в римскую запись
(до 3999).

## Реализация

Экспортируется именованная функция toRoman. Задана коллекция map с парами
[значение, символ]. Пока поданное в функцию число больше или равно текущему
значению - добавляем символ в результат и вычитаем значение из числа. Когда
число становится равным 0, то возвращается накопленная строка.

Граничные случаи:

- если число на входе меньше 1 или больше 3999, бросается RangeError
- если число не целое, бросается RangeError

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
