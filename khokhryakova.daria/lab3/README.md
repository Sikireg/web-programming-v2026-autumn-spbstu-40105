# Лабораторная работа 3

## Задание

Вариант 16. Реализовать функцию `findEquilibriumIndex`, которая находит индекс,
где сумма левой и правой части массива равна.

## Реализация

Экспортируется функция `findEquilibriumIndex`. Сначала вычисляется общая сумма
всех элементов массива, затем массив проходит слева направо с накоплением левой
суммы. Для каждого индекса правая сумма вычисляется как разность общей суммы,
левой суммы и текущего элемента. Если левая и правая суммы равны — возвращается
индекс, иначе `-1`.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
