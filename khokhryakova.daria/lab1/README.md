# Лабораторная работа 1

## Задание

Вариант 16.Создать карточку товара с изображением, названием, кратким описанием
и блоком отзывов.

Требования к карточке:

- фиксированная ширина — 350px;
- изображение занимает верхнюю часть, размер 350×200px;
- название расположено под изображением, шрифт Roboto, 18px, полужирный;
- краткое описание — под названием, шрифт Roboto, 14px, обычный;
- блок отзывов — под описанием, заголовок «Отзывы» — Roboto, 16px, полужирный;
- отзывы отображаются в виде списка `<ul>`;
- каждый отзыв содержит имя пользователя (Roboto, 14px, полужирный) и текст
  отзыва (Roboto, 14px, обычный);
- каждый отзыв отделён от других отступом 10px сверху.

## Реализация

Страница состоит из карточки товара — элемента `<div class="product-card">`.
Внутри карточки сверху вниз расположены:

- изображение — `<img class="product-image">`;
- название — `<h2 class="product-title">`;
- краткое описание — `<p class="product-description">`;
- блок отзывов — `<div class="reviews">`.

Заголовок блока отзывов — `<h3 class="reviews-title">`. Отзывы выводятся списком
`<ul class="reviews-list">`, каждый отзыв — `<li class="review">` с именем
(`<span class="review-name">`) и текстом (`<p class="review-text">`).

## Запуск

Открыть `index.html` в браузере.
