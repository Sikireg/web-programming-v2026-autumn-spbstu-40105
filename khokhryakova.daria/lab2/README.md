# Лабораторная работа 2

## Задание

Вариант 16. Реализовать функцию `isIsogram`, которая проверяет, является ли
строка изограммой — то есть строкой без повторяющихся букв.

Особенности варианта:

- регистр игнорируется: `A` и `a` — одна и та же буква;
- пробелы и дефисы не считаются буквами — они игнорируются при проверке.

Функция возвращает `true`, если строка изограмма, и `false` — иначе.

## Реализация

Экспортируется функция `isIsogram`. Строка приводится к нижнему регистру, затем
из неё удаляются все символы, кроме букв. Оставшиеся буквы проверяются на
уникальность с помощью множества: если буква уже встречалась — функция
возвращает false, иначе true.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
