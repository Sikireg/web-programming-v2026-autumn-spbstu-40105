# Лабораторная работа 1

## Задание

Вариант 26. Создать горизонтальное навигационное меню, где активный элемент
выделяется другим цветом. Для реализации можно использовать `<nav>`, `<ul>`,
`<li>`, и `<a>`. Один из пунктов меню должен быть активным (например, при помощи
class="active").

## Реализация

Меню сверстано с помощью списка `<ul>` внутри тега `<nav>`. Пункты выстроены в
горизонтальную строку с помощью `display: inline-block`. Активный пункт ("О
нас") выделен синим цветом и жирным шрифтом через класс `.active` в файле
`styles.css`.

## Запуск

Откройте `index.html` в браузере.
