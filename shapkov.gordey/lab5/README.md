# Лабораторная работа 5

## Задание

Вариант 26. Реализовать сортировку книг в книжном интернет-магазине. Создать
список книг, который будет содержать обложку книги, название, рейтинг, описание
и цену. Над списком книг нужно создать кнопки Название, Цена, Рейтинг, при
нажатии на кнопку она должна выделяться (например, цветом) и добавлять стрелочку
для каждого варианта сортировки (↑, ↓), а книги выводить в отсортированном виде.
Порядок сортировки: по возрастанию, по убыванию, не задано.

## Реализация

Приложение написано на React. Список книг хранится в константе. При клике на
кнопку сортировки список перестраивается в нужном порядке. Повторный клик по той
же кнопке меняет направление (возрастание → убывание → сброс). Активная кнопка
подсвечивается синим цветом. Все данные хранятся локально, внешние запросы не
используются.

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной.
