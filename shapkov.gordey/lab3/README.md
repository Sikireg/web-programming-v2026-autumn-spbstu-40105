# Лабораторная работа 3

## Задание

Вариант 26. Реализуйте функцию removeDuplicates(arr), которая возвращает новый
массив без дубликатов. На вход подается массив с числами, например: [1, 2, 2, 5,
6, 7, 5], на выходе должен получиться массив: [1, 2, 5, 6, 7].

## Реализация

Пробегаем по исходному массиву и добавляем каждый его элемент в новый массив,
если он уже не добавлен.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
