# Лабораторная работа 3

## Задание

Вариант 37. Реализуйте функцию zipArrays(...arrays), которая объединяет массивы
поэлементно (например, zipArrays([1, 2], ['a', 'b']) → [[1, 'a'], [2, 'b']])

## Реализация

Функция принимает любое число массивов. Внешний цикл идёт по позициям первого
массива. Для каждой позиции внутренний цикл проходит по всем массивам и собирает
из их элементов на этой позиции одну группу, которая добавляется в результат.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
