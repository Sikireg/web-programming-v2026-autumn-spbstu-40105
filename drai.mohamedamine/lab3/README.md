# Лабораторная работа 3

## Задание

Вариант 7. Реализовать функцию `difference(arr1, arr2)`, которая возвращает
массив элементов, которых нет во втором массиве.

## Реализация

Экспортируется функция `difference`. Используется `Set` для быстрой проверки
наличия элементов из второго массива, затем метод `filter` для создания нового
массива с элементами, отсутствующими во втором массиве. Исходные массивы не
изменяются.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
